## 어떤 게임인가요?

2단부터 9단까지 섬이 하나씩 있고, 섬마다 그 단의 바다 친구가 살아요. 구구단을 익힐수록 친구가 **알 → 아기 → 성장 → 황금**으로 자라요. 친구들의 생김새에는 그 단의 숫자가 숨어 있어요. 8단 문어는 다리가 8개, 5단 불가사리는 팔이 5개인 식이에요.

| 단 | 친구 | 숫자 힌트 |
|---|---|---|
| 2단 | 투투 (쌍둥이 해마) | 늘 둘이 붙어 다녀요 |
| 3단 | 삼삼이 (세 꼬리 금붕어) | 꼬리가 세 갈래 |
| 4단 | 포포 (네 지느러미 거북) | 지느러미 네 개 |
| 5단 | 오별이 (불가사리) | 팔 다섯 개 |
| 6단 | 육각이 (눈꽃 해파리) | 여섯 갈래 눈꽃 무늬 |
| 7단 | 칠색이 (무지개 물고기) | 일곱 빛깔 비늘 |
| 8단 | 팔팔이 (문어) | 다리 여덟 개 |
| 9단 | 구름이 (고래) | 아홉 갈래 물줄기 |

섬은 쉬운 단부터 열려요. **2 → 5 → 3 → 4 → 6 → 9 → 7 → 8** 순서예요.

## 구구단 익히기: 한 섬에 네 계단

| 계단 | 게임 | 하는 일 | 다음 계단으로 |
|---|---|---|---|
| 🥚 알 찾기 | 🎵 따라 하기 · 🌈 무지개 징검다리 | 구구단을 듣고 한 줄씩 세 번 따라 말한 뒤, ×1부터 ×9까지 순서대로 건너요 | 징검다리를 모두 건너면 알을 찾아요 |
| 🐣 부화 | 🫧 섞어 풀기 | 순서를 섞은 10문제를 보기에서 골라요 | 한 번에 7개 맞히면 알이 깨어나요 |
| 🐟 성장 | 🐚 조개 숫자판 | 보기 없이 숫자판으로 답을 직접 써요 | 한 번에 7개 맞히면 자라요 |
| 👑 황금 | 🦈 상어 보스전 | 맞힐 때마다 물대포로 상어 체력을 깎아요. 자주 틀린 문제가 더 자주 나와요 | 상어를 이기면 황금이 돼요 |

- **시간 제한이 없어요.** 틀리면 묶음 그림 힌트(예: 7개씩 3묶음)가 나오고, 틀려도 별을 깎지 않아요.
- 정답을 맞히면 "칠삼, 이십일"처럼 **구구단을 소리 내어 읽어 줘요.**
- **📅 오늘의 복습**: 자주 틀리거나 오래 걸린 문제 5개를 매일 모아서 풀어요. 연달아 세 번 빨리 맞히면 복습 목록에서 빠져요.

## 어항에서 친구 돌보기

- **밥 주기, 청소, 약**: 친구는 12시간이 지나면 배고파해요. 똥이 쌓이면 유리에 이끼가 끼고, 가끔 아프기도 해요. 절대 죽지는 않아요.
- **친밀도 💗**: 밥 주기, 쓰다듬기, 공놀이, 부탁 들어주기로 친해져요. 친해질수록 재주넘기와 춤을 하고, 가장 친해지면 아이 이름을 불러 줘요.
- **📋 오늘의 부탁**: 친구들이 매일 부탁 3개를 해요. 다 들어주면 도장을 받고, 도장 7개를 모으면 큰 선물이 있어요.
- **🎁 깜짝 선물**: 친한 친구가 가끔 모래에서 보물을 찾아와요.
- **🦀 놀러 오는 손님 7명**: 좋아하는 장식을 어항에 놓으면 손님이 놀러 와서 구구단 수수께끼를 내요.
- **🪸 꾸미기**: 장식 25종과 배경 4종을 별로 사서 원하는 곳에 놓아요.
- **🪪 네임카드**: 친구마다 생일, 물고기 나이, 특징, 그 단의 실력이 담긴 카드가 있어요. 황금 친구는 반짝이는 홀로그램 카드예요.
- **🗺️ 모험 지도**: 상어가 돌아다니고 돌고래가 뛰어오르는 바다를 배를 타고 건너요.
- 잔잔한 배경음악과 효과음이 있어요. 문제를 풀 때는 조용해져요.

## 보호자 화면

어항 오른쪽 위 **🔒 보호자**를 누르고 곱셈 문제를 풀면 들어갈 수 있어요.

- 오늘과 최근 7일 학습 시간, 연속 출석
- **구구단표 정답률**: 2~9단 × 1~9 칸마다 색으로 보여줘요. 새로 외울 36문제 중 몇 개를 익혔는지도 알려줘요.
- 자주 틀리는 문제, 섬별 진행 상황
- 아이 이름, 효과음과 배경음악, 읽어 주는 목소리 설정
- **진행 기록 옮기기**: 다른 기기나 다른 주소로 기록을 옮기는 코드를 만들고 가져와요.

## 태블릿에 앱으로 설치하기

1. 태블릿 브라우저에서 **https://cookcho.github.io/gugudan-aquarium/** 을 열어요.
2. **갤럭시탭 (Chrome)**: ⋮ 메뉴 → "홈 화면에 추가" 또는 "앱 설치"  
   **아이패드 (Safari)**: 공유 버튼 → "홈 화면에 추가"
3. 홈 화면에 생긴 **"구구단 어항"** 아이콘으로 열면 주소창 없이 전체 화면으로 열려요. 한 번 열어 두면 인터넷이 없어도 열려요.

> 가로 화면에 맞춰 만들었어요. 진행 기록은 그 기기의 브라우저에만 저장되고, 어디로도 보내지 않아요.

**읽어 주는 소리가 안 나오면**: 태블릿 설정에서 글자 읽어주기(텍스트 음성 변환) 엔진과 한국어 음성을 설치해 주세요. 보호자 화면에 자세한 방법이 있어요.

## 개발

Vite와 순수 JavaScript로 만들었어요. 프레임워크나 서버는 없어요.

```bash
npm install
npm run dev      # 개발 서버 (같은 와이파이의 태블릿에서 http://PC주소:5173 으로 접속)
npm run build    # dist/ 에 배포용 파일 만들기
```

- `main` 브랜치에 올리면 GitHub Actions가 자동으로 GitHub Pages에 배포해요.
- **캐릭터 그림**: `public/characters/단-단계.png` (단계: 1 알 · 2 아기 · 3 성장 · 4 황금, 안내 캐릭터는 `guide.png`). 그림이 없는 칸은 코드로 그린 그림이 나와요. 이미지 AI로 만든 큰 그림을 넣고 `npm run optimize-images`(또는 `npm run dev`)를 실행하면 512px로 줄이고 가짜 배경을 지워요. 원본은 `art-source/`에 따로 보관해요(저장소에는 올리지 않아요).

```
src/
  scenes/     화면 (어항, 지도, 게임들, 결과, 보호자, 손님)
  core/       저장, 읽어 주기 음성, 문제 만들기, 헤엄 움직임
  data/       친구, 상점, 돌보기 규칙, 손님
  graphics/   코드로 그린 캐릭터와 장식
  audio/      효과음과 배경음악 (Web Audio로 직접 연주)
```
